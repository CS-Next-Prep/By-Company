# ByCompany

> Pick a company. See what they've actually asked in interviews.

Built and maintained by **CS-Next** — *For the pursuit of excellence.*

---

ByCompany is a free, static reference for students and engineers preparing for technical interviews. Search across 656 companies, filter by difficulty or topic, compare two companies side-by-side, or hit Surprise me for a random question. No account, no paywall, no ads.

Every question links to the original LeetCode problem. No problem statements are reproduced here — title, difficulty, frequency, and link only.
